# Desktop localization

English and French are selected in Settings → App language. The first launch follows the system language when French is preferred, then saves the explicit selection in `coroslink.language`. The preload bridge mirrors the preference to the desktop database for native menus and file dialogs. A language change updates subscribed React components without remounting them.

Use `t("English source", { count })` with named `{{count}}` placeholders. English source text is the fallback. Add French entries to the appropriate `fr/core.ts`, `fr/training.ts`, `fr/tools.ts`, or `fr/watchfaces.ts` catalog. Call `useLanguage()` at the top of each translated React component, and include its `language` value in memo dependencies when the cached result contains translated text. Translate static option labels when they are read, rather than when a module is initialized. Each domain imports its scoped module (`i18n/training`, `i18n/watchfaces`, or `i18n/tools`) so words such as Weight and Stroke keep their context. Pure helpers use the corresponding `trainingLocale`, `watchfacesLocale`, or `toolsLocale` module to avoid loading React. Pass `translateLabel={t}` to shared dropdowns to retain that context.

Use `getLocale()`, `formatDate()`, and `formatNumber()` for presentation. Keep ISO date keys, API payloads, enum values, CSS names, React keys, filenames, exercise names, watch artwork and user/provider content in their original form. `src/units/units.ts` applies the selected number locale without changing shared conversions. Native UI translations live in `electron/localization.ts`; dialog translation preserves file paths, extensions and button indexes.

To add another language, extend `Language`, `LANGUAGES`, `resolveLanguage`, `getLocale` and the catalog selection in `locale.ts`, then add the native menu/dialog catalog. Run `npm run test:localization` and `npm run build`. The localization tests cover preference precedence, restricted storage, interpolation, English fallback, subscription cleanup, French number/date/unit formatting, live switching, form state and unchanged save payloads.
