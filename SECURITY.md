# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report them privately through GitHub instead:

1. Go to the [Security tab](https://github.com/JunAkerBuilds/CorosLink/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem, the version you saw it on, and how to reproduce it.

Only the maintainers can see the report. We'll reply there, and once a fix ships we'll publish an advisory and credit you unless you'd rather stay anonymous.

## Supported versions

Fixes go into the latest release. Please check that the problem still happens on the [newest version](https://github.com/JunAkerBuilds/CorosLink/releases/latest) before reporting.

## What's in scope

- The CorosLink and C-LINK desktop apps in this repository
- The relay and website code in this repository

Problems in COROS's own apps, watches or services are out of scope. Please report those to COROS.
